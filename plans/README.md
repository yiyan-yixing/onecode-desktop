# Plans & Tasks / 计划与任务

> 此目录记录 onecode-desktop 接下来的开发计划和任务。

## 目录结构

```
plans/
├── README.md        — 本文件，计划索引
├── backlog.md       — 待办事项池（未排期）
├── roadmap.md       — 路线图（按阶段排列）
└── active/          — 当前活跃的计划（按主题拆分）
```

## 使用方式

- **backlog.md** — 想法、需求、bug 丢进池子，未排期
- **roadmap.md** — 按阶段（v0.x → v1.0）排列的里程碑
- **active/** — 正在推进的具体计划，每个主题一个文件，完成后归档或删除

## 状态约定

| 标记 | 含义 |
|------|------|
| 🔴 | 阻塞 / 未开始 |
| 🟡 | 进行中 |
| 🟢 | 已完成 |
| ⏸️ | 暂停 |
| ❌ | 取消 |
